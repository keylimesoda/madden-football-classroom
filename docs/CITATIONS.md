# Citation and evidence policy

MFC separates claims by what they describe.

1. **Official Madden source** — EA controls, Gridiron Notes, and official game pages. Use for stated features and control mappings.
2. **MFC observed behavior** — a reproducible in-game test with platform, game version, patch date, and capture. Label it **observed**, not “verified.”
3. **Football concept source** — coaching, rules, or credible film-study material. Use for terminology and conceptual explanations.
4. **Madden specialist** — creators and competitive players help with current practice, playbook locations, and counterexamples. Label opinion and game year.
5. **Community report** — a lead for review, never the only support for a factual claim.

Every course should have a `Sources and further study` section. Videos get creator, exact title, published/game version context, link, and the specific reason MFC recommends it. MFC links or embeds external video; it does not download or re-upload it.
