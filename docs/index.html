The first practical win

Build a calm plan before the ball moves.

Do not pretend you can identify every coverage from one look. You can still make a useful plan: spot the shell, count the box, notice leverage, and decide what you will check first.

01 · SPOT IT

Start with the safeties

One-high or two-high is the fast picture. It shapes where the defense may have help, not a guarantee of the final coverage.

Animated diagram
02 · COUNT IT

Count the box

Count defenders near the line against blockers and runners. A run is not brave because you called it into bad numbers.

Practice-mode lab
03 · PLAN IT

Name your first answer

Choose a first read and a safe answer. You are making a plan, not marrying a throw before the snap.

Quick check
Practice lab · 3 minutes

Read it. Say it. Run it.

In Practice Mode, call the same formation against a two-high shell and a one-high shell. Before each snap, say the four-part scan out loud.

01Shell: “One high” or “two high.”
02Box: “I have / do not have numbers for the run.”
03Leverage: “The corner is inside/outside, press/off.”
04Plan: “I will check ___ first, then take ___ if it is gone.”
