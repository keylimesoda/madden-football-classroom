# Contributing to MFC

Thank you for helping people learn football through Madden.

Please open an issue before making a large lesson or diagram contribution. We accept four review-queue types:

- **Correction:** affected claim, game/version, source or reproduction, proposed correction.
- **Source recommendation:** source link, claim it supports, creator/copyright context.
- **Lesson proposal:** learner win, football concept, Madden translation, diagram idea, sources.
- **Version drift:** prior behavior, current behavior, platform, patch, reproduction steps, capture if available.

## Editorial rules

- Teach decisions and constraints, not “unstoppable” exploits.
- Mark Madden 27 behavior separately from evergreen football concepts.
- Use original diagrams. Link/embed third-party media unless the creator grants written reuse permission.
- Cite the best source available under [the citation policy](docs/CITATIONS.md).
- Keep a micro-course finishable in 5–10 minutes.

Pull requests require review before publication.
