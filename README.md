# Madden Football Classroom

**Learn football. Play Madden better.**

Madden Football Classroom (MFC) is an open, visual, short-course curriculum for people who play Madden and want to understand the football decisions underneath each snap.

- Madden NFL 27-first; game mechanics carry a visible version label.
- 5–10 minute courses with animated Xs-and-Os, short checks, and Practice Mode labs.
- Original diagrams and cited external material.
- No account needed. Progress is stored locally in the browser.

## Start here

- **MFC 101.1 — The Pre-Snap Scan:** shell, box count, leverage, and a calm plan.
- **MFC 101.2 — Shells: One High and Two High:** identify the safety picture without treating it as a coverage guarantee.
